## Overview

**Etern Studio** is the official portfolio and hub for indie games built with Unity, open-source software tools, and digital media created by **EternoDev (Pau CG)**.

Designed with a modern, high-performance dark aesthetic inspired by **GDevelop**, featuring an interactive games carousel dynamically linked to **Itch.io**, application showcase cards, creator biography, and community integration.

---

## Featured Projects

### Video Games (Unity / C#)
- **Awaked: SSS-Rank**: Action roguelike dungeon crawler with procedural progression and frenetic combat.
- **Stickman LevelUp**: Retro arcade platformer with fast reflexes and level-based challenges.
- **GameJam Editions**: Rapid prototypes developed in 48-hour game jam events.

### Applications & Tools
- **BrightLight**: Web Bluetooth controller for smart BLE lights (Triones, HappyLighting, IP66).
- **Etern-Notes**: Cross-platform Kanban task manager and note-taking tool for developers.
- **Etern-Synth**: Retro 8-bit sound effects synthesizer for indie game developers.
- **Etern-Audio**: Soundboard and instant audio library for content creators.
- **Etern-Ref**: Infinite canvas for visual references, moodboards, and relational concept maps.

---

## Tech Stack

- **Frontend**: HTML5 Semantic Architecture, CSS3 Modern Flexbox/Grid, JavaScript (ES6+).
- **Integrations**: Itch.io RSS Feed Integration & Fallback Caching, GitHub API.
- **Hosting**: 100% Client-Side on GitHub Pages (Zero backend dependency).
