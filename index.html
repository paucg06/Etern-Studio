BrightLight

Controlador Web Bluetooth profesional para bombillas y tiras LED BLE (Triones / HappyLighting / IP66).

  • Sin instalación: 100% Web Bluetooth API
  • Gestión multi-luz sincronizada e individual
  • Motor de secuencias y fundidos personalizados

Etern-Notes

Gestor Kanban y bloc de notas de alta velocidad optimizado para desarrolladores y estudiantes.

  • Tableros Kanban por proyectos y estados
  • Multiplataforma: Windows, Linux y macOS

En Desarrollo

Etern-Synth

Sintetizador generativo de efectos de sonido retro para videojuegos indie (estilo SFXR/BFXR).

  • Generación de saltos, explosiones y monedas
  • Modulación paramétrica de ondas en tiempo real
  • Exportación directa a formato WAV y MP3

Próximamente

Etern-Audio

Soundboard y buscador rápido de archivos de audio diseñado para creadores de contenido y streamers.

  • Búsqueda y preescucha instantánea de clips
  • Asignación de atajos de teclado globales
  • Integración fluida con software de grabación
